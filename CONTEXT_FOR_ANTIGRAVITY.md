# 🧠 КОНТЕКСТ ПРОЕКТА: DYNAMIC ISLAND PRO (ULTIMATE EDITION)

> **Версия 2.0 (Ultimate Edition):** Полнофункциональный интерактивный Dynamic Island для Windows 10/11, объединяющий возможности классического лаунчера, панели продуктивности и компаньона для AI-агентов (TwoCode / coucou / NotchNook).

---

## 🚀 1. Архитектура и стек
* **Ядро:** Python 3.13, PyQt6, psutil, ctypes (Win32 API).
* **Свойства окна:**
  * `Qt.WindowType.FramelessWindowHint` + `Qt.WidgetAttribute.WA_TranslucentBackground` — прозрачный ARGB холст без системных белых рамок.
  * `Qt.WindowType.WindowStaysOnTopHint` + `user32.SetWindowPos(HWND_TOPMOST)` — держится поверх всех окон.
  * `Qt.WindowType.Tool` — не засоряет панель задач и Alt+Tab.
* **Встроенный IPC HTTP Сервер:**
  * Порт: `http://127.0.0.1:28282` (фоновый поток daemon).
  * Позволяет любому агенту (Antigravity, Claude Code, Codex, Python-скриптам) слать события в 1 строку через curl или requests:
    * `POST /api/status` — обновление статуса (`working`, `idle`, `action`, `agent`).
    * `POST /api/ask` — запрос интерактивного подтверждения у пользователя (кнопки `Allow` / `Deny`).
    * `POST /api/done` — звуковой Chime и победная анимация завершения.
    * `GET /api/status` — считывание состояния.

## 🎨 2. Режимы отображения и вкладки

### 1. Режим «Капелька» (В покое / Collapsed)
* **Размер:** `140 × 24 px` (в режиме покоя) и адаптивное расширение до `260 × 24 px` при активности AI.
* **Индикаторы:**
  * Эмодзи-маскот Robo (`🤖` в покое, `⚡` в работе, `❓` при вопросе, `🎉` при победе).
  * Название и бегущая строка действия агента.
  * Процент нагрузки CPU % в акцентном цвете.

### 2. Режим «Пульт» (Expanded Dashboard — 540 × 290 px)
Удобная навигация по 6 функциональным вкладкам:
1. **🚀 Главная (Launchpad):**
   * Графики загрузки CPU и RAM в реальном времени.
   * Сетка быстрых плиток приложений (Launchpad).
   * Управление мультимедиа (YouTube, Spotify, Яндекс Музыка) с распознаванием названий треков и виртуальными кнопками громкости/переключения.
   * Строка мгновенного поиска в Google и запуска ссылок.
2. **🤖 AI Агент (AI Companion):**
   * Интерактивный Robo (меняет эмоции при клике).
   * Карточка текущего статуса агента.
   * Кнопки `[✅ Одобрить (Allow)]` и `[❌ Отклонить (Deny)]` для подтверждения команд без переключения в терминал.
   * Кнопки быстрого тестирования режимов.
3. **📋 Буфер (Clipboard History):**
   * Автоматический перехват новых фрагментов из буфера обмена Windows.
   * История последних 12 записей.
   * Клик по любой записи мгновенно возвращает её в буфер.
4. **⏱️ Фокус (Pomodoro Timer):**
   * Таймер 25 минут фокуса / 5 минут отдыха.
   * Звуковое оповещение по окончании времени.
5. **📝 Заметки (Scratchpad):**
   * Быстрый блокнот прямо у кромки экрана для промптов и мыслей.
   * Автоматическое сохранение текста в файл `scratchpad.txt`.
6. **⚙️ Опции (Settings):**
   * Слайдер регулировки прозрачности стекла (30% - 100%).
   * Палитра из 6 неоновых акцентных цветов.
   * Добавление/удаление пользовательских кнопок лаунчера.
   * Тумблер системных звуков (Chime / Beep).

## 🎮 3. Запуск приложения
* **Обычный запуск:** `python main.py`
* **Фоновый запуск без консоли:** дважды кликнуть по `run.vbs`
* **Ярлык на рабочем столе:** запустить `create_desktop_shortcut.bat`
