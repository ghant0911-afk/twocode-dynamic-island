# 🏝 TwoCode Dynamic Island Pro (Portable Edition)

Портативный автономный Dynamic Island в стиле TwoCode для Windows с живым анимированным маскотом Robo, управлением мультимедиа, скриншотами, буфером обмена и интеграцией с AI (Antigravity, Claude Code, OpenAI Codex).

---

## 🚀 Быстрый запуск на новом ПК (Дома)

1. Убедитесь, что на компьютере установлен **Python 3.10+** (при установке обязательно поставьте галочку `Add Python to PATH`).
2. Скопируйте папку `Dynamic_Island_Work` в любое удобное место (например, на диск `D:\` или `C:\`).
3. Запустите двойным кликом:
   ```cmd
   install_and_run.bat
   ```
   Этот скрипт сам установит нужные библиотеки (`PyQt6`, `psutil`, `pywin32`, `Pillow`), создаст ярлык на рабочем столе и сразу запустит остров!

---

## 🕹 Как управлять островом

* **Капелька (Notch)**: висит вверху по центру экрана под панелью задач или на верхней рамке (`118x26` px).
* **Живой робот**: в капельке живет анимированный Robo:
  - Клик левой кнопкой мыши по роботу переключает эмоции (`радость`, `подмигивание`, `сердечки ♥`, `чтение 📖`, `музыка 🎵`, `размышления 💡`).
* **Наведение мыши**: карточка плавно раскрывается в полноценную панель управления (`440x136` px).
* **Увод мыши**: карточка плавно сворачивается обратно в компактную каплю.
* **Перемещение**: зажмите левую кнопку мыши в любом месте и перетаскивайте остров на любой монитор. Если отпустить рядом с верхней кромкой экрана — он сам аккуратно примагничивается в центр!
* **Кнопка `🎯`**: мгновенно выравнивает остров по центру активного экрана.
* **Мультимедиа**: универсальные аппаратные клавиши (`⏮`, `⏯`, `⏭`, `🔉`, `🔊`) управляют любым плеером (Яндекс.Музыка, Spotify, YouTube, браузер).
* **Скриншоты `✂️`**: вызывает инструмент выделения прямоугольной области Windows.
* **Буфер обмена `📋`**: открывает историю буфера обмена (`Win+V`).

## ⚙️ Структура проекта

* `main.py` — основной исполняемый код приложения на PyQt6.
* `launch.vbs` — тихий запуск в фоне без черного окна консоли.
* `start.bat` — запуск через pythonw.
* `install_and_run.bat` — первичная установка зависимостей и запуск в 1 клик.
* `create_shortcut.py` — скрипт генерации ярлыка на рабочем столе.
* `config.json` — сохраненные пользовательские настройки (звук, координаты).
* `assets/` — иконки, звуки, макеты TwoCode и анимации.

## 🌐 HTTP API для подключения любых агентов

Остров слушает локальный порт `http://127.0.0.1:28282`:
* `GET /status` — проверка статуса.
* `POST /api/status` — передача текущего состояния агента (дифф кода, имя файла, действие).
* `POST /api/done` — праздничный сигнал завершения задачи (робот салютует, звучит победный перезвон).
* `POST /api/ask` — запрос подтверждения действия пользователя (кнопки Allow / Deny).
