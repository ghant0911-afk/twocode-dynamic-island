# TwoCode Dynamic Island Pro 🏝️🤖

Реплика интерактивного острова TwoCode Dynamic Island для Windows с живым векторным маскотом-компаньоном, объединяющим эмоции роботов **Loona** (KEYi Tech), **EMO** (LivingAI) и **Nuwa/Nusa**.

## ✨ Особенности

- 🏝️ **Динамический остров TwoCode**: ультракомпактная капелька (118x26 px) при работе в фоне, плавно раскрывающаяся в многофункциональную карточку (440x136 px).
- 🧠 **Собственный интеллект (Companion Brain)**: робот понимает вопросы, команды управления музыкой, запрос скриншотов, шутит, считает математику и поддерживает живой диалог.
- 🗣️ **Голос и анимация речи (SAPI5 TTS)**: живая русская озвучка, синхронизированная с анимированным ртом/визором во время разговора.
- 🐾 **Автономная жизнь (Life Engine)**: робот живёт собственной жизнью — самостоятельно оглядывается по сторонам, меняет эмоции, реагирует на клики и засыпает при долгом бездействии.
- 🤖 **18 живых эмоций маскота**:
  - `idle`, `love` (сердечки Loona), `star` (звезды победы), `puppy` (аниме-глазки с бликами), `curious`, `cool` (очки EMO), `music` (эквалайзер + наушники + бит), `thinking` (вычисления + лампочка 💡), `reading` (лазерный сканер + книга 📖), `happy`, `wink`, `shy`, `sad` (слезинка 💧), `gaming` (8-бит ретро 👾), `dizzy` (спирали @ @), `grumpy` (сердитый), `sleepy` (сонные веки + zZ), `shocked` (!).
- 💬 **Встроенный чат с Antigravity**: окно ввода с фокусом по умолчанию.
- 📄 **Мониторинг диффов кода**: подсветка добавленных и удаленных строк в реальном времени.
- 🎵 **Универсальное управление звуком**: нативные кнопки Windows для переключения треков и паузы в любом плеере (Яндекс.Музыка, Spotify, Браузер, VK Музыка, AIMP).
- ✂️ **Встроенный Snipping Tool**: снимок прямоугольной области экрана в один клик.
- 📋 **Менеджер буфера обмена**: вызов истории буфера Windows.
- 🔌 **Локальный IPC HTTP API (порт 28282)**: интеграция с внешними скриптами и переключение эмоций налету.

## 🚀 Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запуск в один клик без черного окна консоли:
- Запустите `launch.vbs` или используйте созданный ярлык на Рабочем столе `TwoCode Dynamic Island.lnk`.

## 📡 API Управление эмоциями

```bash
# Получить статус
curl http://127.0.0.1:28282/status

# Установить эмоцию (например, love, star, puppy, music, cool, gaming)
curl -X POST http://127.0.0.1:28282/api/emotion -H "Content-Type: application/json" -d "{\"emotion\": \"love\"}"
```
