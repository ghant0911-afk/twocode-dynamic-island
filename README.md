# TwoCode Dynamic Island Pro 🏝️🤖

Реплика интерактивного острова **TwoCode Dynamic Island** для Windows с живым векторным маскотом-компаньоном, объединяющим эмоции роботов **Loona** (KEYi Tech), **EMO** (LivingAI) и **Nuwa/Nusa**, с собственной голосовой личностью на базе **Silero Neural TTS (Байя 48 kHz)** и системой голосового управления через микрофон.

---

## ✨ Ключевые возможности

### 1. 🎙️ Голосовой ввод и непрерывный диалог (Hands-Free Voice Companion)
- **Активация по имени (Wake Word)**: скажите в микрофон *«Байя»*, *«Привет»* или *«Остров»* — остров раскроется и начнет слушать вас.
- **Сессия живой беседы (15 сек)**: после активации слово «Байя» повторять больше не нужно. Маскот поддерживает естественный живой диалог подряд.
- **Переключатель микрофона (Вкл / Выкл)**:
  - 🟢 Кнопка `[🎙️]` в карточке — постоянное фоновое слушание активно.
  - 🔴 Кнопка `[🔇]` в карточке — микрофон выключен (полная приватность).
  - Правый клик по микрофону — немедленная прямая диктовка фразы в чат.
  - Управление микрофоном также доступно через меню в системном трее Windows.
- **Защита от эха (Echo Feedback Suppression)**: микрофон автоматически глушится, пока робот говорит сам.

### 2. 🗣️ Живой нейросетевой голос (Silero Neural 48 kHz)
- Вместо роботизированного синтеза интегрирована нейросеть **Silero v4 (тембр Байя)** студийного качества.
- Очень мягкий, уютный, теплый женский тембр с естественным дыханием и интонациями.
- **0 ms Latency**: ключевые эмоциональные фразы предкэшированы на диск.
- Анимированный рот робота открывается и закрывается в такт реальной речи.

### 3. 🐾 Автономный маскот и 18 эмоций (Loona + EMO + Nusa)
- Размер капли увеличен до комфортных **142x36 px**, размер маскота в капле — **28 px** (в карточке — **52 px**).
- Робот живёт собственной жизнью: оглядывается по сторонам, моргает, танцует под музыку, уходит в сон при простое.
- **18 эмоций**:
  - `idle`, `love` (сердечки Loona), `star` (звезды победы), `puppy` (аниме-глазки с бликами), `curious`, `cool` (очки EMO), `music` (эквалайзер + наушники + бит), `thinking` (вычисления + лампочка 💡), `reading` (лазерный сканер + книга 📖), `happy`, `wink`, `shy`, `sad` (слезинка 💧), `gaming` (8-бит ретро 👾), `dizzy` (спирали @ @), `grumpy` (сердитый), `sleepy` (сонные веки + zZ), `shocked` (!).

### 4. 🛠️ Панель продуктивности
- **Встроенный чат с Antigravity**: быстрый ввод запросов и задач.
- **Мониторинг диффов кода**: подсветка добавленных и удаленных строк в реальном времени.
- **Управление звуком Windows**: пауза/воспроизведение и переключение треков в любом плеере (Яндекс.Музыка, Spotify, Браузер).
- **Встроенный Snipping Tool**: снимок прямоугольной области экрана в один клик.
- **Менеджер буфера обмена**: вызов истории буфера Windows.
- **Локальный IPC HTTP API (порт 28282)**: интеграция с внешними скриптами.

## 🚀 Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запуск острова:
- Запустите `start.bat` или `launch.vbs` (без черного окна консоли).

---

## 📡 Локальный HTTP API (порт 28282)

```bash
# Получить статус острова
curl http://127.0.0.1:28282/status

# Раскрыть / свернуть остров
curl http://127.0.0.1:28282/expand
curl http://127.0.0.1:28282/collapse

# Установить эмоцию (love, star, puppy, cool, music, etc.)
curl -X POST http://127.0.0.1:28282/api/emotion -H "Content-Type: application/json" -d "{\"emotion\": \"love\"}"

# Заставить маскота сказать любую фразу вслух
curl -X POST http://127.0.0.1:28282/speak -H "Content-Type: application/json" -d "{\"text\": \"Привет! Все работает отлично!\"}"
```
